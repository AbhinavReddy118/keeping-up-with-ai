About AI News Dashboard

A personal AI intelligence monitor that continuously tracks, normalizes, deduplicates, analyzes, and ranks developments across the global AI ecosystem.

Pipeline Architecture

RSS / Atom Sources ↓ Generic Ingestion Reader ↓ Schema Normalization ↓ SQLite Article Storage ({{ stats.total_articles }} articles) ↓ Progressive Deduplication ↓ Batch LLM Structured Extraction ({{ stats.analyzed_articles }} analyzed) ↓ Deterministic Ranking Engine ↓ Minimal Web Interface (Flask + Jinja)

Key Guarantees:

  • 100% Read-Only Presentation: Web requests never modify or mutate database records.
  • Structured Intelligence: LLM analysis extracts validated JSON schemas covering relevance, novelty, event classification, and named entities.
  • Deterministic Ranking: Articles are scored dynamically using a normalized weighted formula (40% relevance, 25% novelty, 20% recency, 15% confidence).
  • Inclusive Latest Feed: The latest news section presents ingested developments immediately, clearly designating whether LLM analysis has been completed.
